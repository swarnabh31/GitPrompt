How it works

1

Read the repository

GitPrompt pulls the repo's metadata — or, in Deep Rebuild mode, downloads the full source archive from GitHub.

2

Build context

Overview assembles structure and dependencies instantly. Deep Rebuild selects the most important source files that fit your model's context window.

3

Generate the prompt

Your local Ollama model synthesizes a build specification, wrapped in an agent-ready prompt with an ordered implementation checklist.

GitPrompt Runs locally · Your code never leaves your machine
